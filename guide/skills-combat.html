スキルと戦闘が新しくなりました

スキルと装備の選び方、戦闘の相性、仲間との連携が新しくなりました。

一番大きな変化は、覚えた技を職業だけで縛らず、装備と5ターンの組み合わせで戦い方を作れるようになったことです。敵の弱点や姿勢を仲間と順番に突くと「連携」が続き、後のスレイヤー攻撃ほど大きな威力を出せます。

この案内では、現在の正式な遊び方と、以前から遊んでいる人が確認してほしい点を説明します。

最初に確認すること

以前から遊んでいる人は、次の3つを一度確認してください。

  1. /statusで、現在の装備と能力を確認する。
  2. /skillsで、今の装備で使用できる技と必要装備を確認する。
  3. /skillsの「スキルセット変更」で、1〜5ターン目とパッシブ枠を確認する。

習得済みの技や所持装備は引き継がれています。ただし、現在の装備では使えない技が設定から外れている場合があります。空いたターンは通常攻撃になるため、次の戦闘前に組み直しておくのがおすすめです。

/skillsの習得一覧とスキルセット変更候補では、装備が必要な技に次のような案内が表示されます。

覚えた職業と、使える職業は別

職業は、主に技を覚えるきっかけと能力配分を決めます。

一度覚えた技は、転職しても失いません。現在の職業だけを理由に使えなくなることもありません。別の職業で覚えた攻撃、回復、補助を組み合わせられます。

一方、剣技には剣、魔石の固有技には対応する魔石というように、技ごとの装備条件は残ります。現在の装備が条件を満たさない技は設定できません。

習得できる技は20個まで

習得済みの技は、A・S・Pを合わせて最大20個です。

職業レベルが3、6、9、12、15へ到達すると、対応する技をすぐ覚えるのではなくスキル書を1冊得ます。/skills から好きなタイミングで読めます。

20個覚えているときにスキル書を読む場合は、覚えている技を1つ選び、新しい技と入れ替えます。入れ替えを完了するまでスキル書は消費されません。

好きなときに忘却だけを行うことはできません。

装備が戦い方を作る

装備枠は、武器・魔石・霊符の3つです。

装備主に関わるもの例
武器力、近・中・遠の攻撃、武器固有技剣、槍、弓、砲など
魔石魔力、風・火・水・大地、魔石固有技竜巻、灼熱、山など
霊符霊力、聖・邪、霊符固有技祈り、裁き、呪いなど

装備は能力を上げるだけではありません。攻撃の属性、相手に突ける弱点、自分が受ける攻撃への耐性、設定できる固有技も変わります。

装備変更後は、/skillsの現在設定と候補を確認してください。条件を満たさなくなった行動スキルやパッシブは使用できません。

武器を装備していない場合は、未設定ターンに素手の近距離通常攻撃を行います。魔石や霊符を装備していないとき、装備属性を任意で参照できる技は無属性になります。特定の装備そのものを必要とする固有技は、未装備では使えません。

スレイヤーとレジスト

戦闘の有利・不利は、主に「スレイヤー」と「レジスト」で表示されます。

スレイヤー

攻撃が、相手の弱点と一致したときに成立する有利な相性です。成立した攻撃は威力が上がり、連携が1つ進みます。

→ 翼竜：40ダメージ（リフトスレイヤー・1連携）

スレイヤーには、火や風などの属性を突くものと、リフトやダウンという姿勢を突くものがあります。

レジスト

攻撃の属性や性質が、相手の耐性に阻まれたときに成立します。ダメージが減る場合と、攻撃そのものを回避する場合があります。

→ ミナ：18ダメージ（火レジスト）

1回の攻撃に複数の力が含まれる場合、一部でスレイヤー、別の一部でレジストが同時に成立することもあります。

属性は装備でも変わる

魔石や霊符は、対応する攻撃の属性とスレイヤー、装備者自身の弱点とレジストに関わります。

攻撃属性とスレイヤーは同じ意味ではありません。たとえば火の攻撃が、火に弱い相手だけでなく、装備の組み合わせによって別の弱点を突く場合があります。実際に何が成立したかは、戦闘ログの「○○スレイヤー」「○○レジスト」で確認できます。

リフトとダウン

リフトとダウンは、相手へ付けて連携の起点にできる「姿勢」です。

リフトリフトスレイヤーダウンスレイヤー
ダウンダウンスレイヤーリフトスレイヤー

→ 敵にリフトを付与した。

注意点は次のとおりです。

  • リフトスレイヤーだけでは、相手を自動でダウンにしません。
  • ダウンスレイヤーだけでは、相手を自動でリフトにしません。
  • 姿勢を変える技には、攻撃とは別に「リフトを付与」「ダウンを付与」と表示されます。
  • すでにリフトかダウンになっている相手へ、通常の姿勢を重ねて付けることはできません。
  • 一時姿勢は付与した次のターン終了まで続きます。対応するスレイヤーを受けた場合は、その攻撃行動が終わった後に解除されます。
  • 飛行や低姿勢による常態リフト・常態ダウンは自然に消えず、スレイヤーを受けても維持されます。

多段攻撃では、攻撃の途中で一時姿勢が解除されません。3回攻撃のすべてが同じ姿勢を突けば、3ヒットともスレイヤーになり得ます。

連携の仕組み

スレイヤーが成功するたび、攻撃を受けた相手ごとに連携数が増えます。攻撃した本人だけの記録ではないため、パーティの別の仲間が続けて弱点を突いても同じ連携になります。

プレイヤーA：リフトを付与
プレイヤーB：リフトスレイヤー・1連携
プレイヤーC：属性スレイヤー・2連携

姿勢スレイヤーの次に属性スレイヤーを使うなど、種類の違う弱点でも連携は続きます。

1ヒットごとに1連携

  • スレイヤーが1つ以上成立したヒットは、連携が1増えます。
  • 1ヒット内で複数のスレイヤーが成立しても、増えるのは1だけです。
  • スレイヤーとレジストが同じヒットで成立した場合も、スレイヤーが成功していれば1増えます。
  • 多段攻撃は、ヒットごとに数えます。
  • 連携倍率が乗るのは、そのヒット自身でもスレイヤーが成功した場合だけです。

連携数に上限はありません。長く続けるほど威力が大きくなります。

連携が切れるとき

その相手に対して、1ターン中にスレイヤーが1回も成功しなければ、ターン終了時に連携は0へ戻ります。

通常攻撃、レジストだけの攻撃、回避された攻撃では連携を維持できません。ただし、同じターンの後の攻撃でスレイヤーが成功すれば維持されます。相手が戦闘不能になった場合も連携は0になります。

パーティで連携を作る

パーティ内の基本行動順は、/partyで決めた順番です。敵側も敵パーティに定義された順番で行動します。敏捷値による毎ターンの抽選はありません。

次のターンだけパーティ内の最初または最後に動かす技もあります。FirstとLastはパーティ内でそれぞれ1人だけで、同じ指定を複数人が使った場合は後から使った指定が優先されます。

連携を組むときは、次の役割を順番に置くと考えやすくなります。

  1. 姿勢や属性弱点を用意する。
  2. スレイヤーで弱点を突く。
  3. 次の仲間が突ける姿勢を付ける。
  4. 別のスレイヤーで連携を続ける。

代表例は次のとおりです。

浮身崩し       → リフトを付与
天穿           → リフトスレイヤー + ダウンを付与
貫通突き       → ダウンスレイヤー + リフトを付与
狙い射ち       → リフトスレイヤー

技の副次効果による姿勢付与は、その攻撃でスレイヤーが成功したかどうかとは別に処理されます。ログに表示された付与結果を見て、次の戦闘で行動順を調整してみてください。

フィールド・バリア・防壁

似た名前ですが、それぞれ役割が違います。

要素効果
フィールド展開中と同じ魔石属性（風・火・水・大地）の攻撃成分を1.2倍にする
バリア味方全員へ対応する属性レジストを付ける
防壁属性に関係なく、決められた攻撃のダメージを軽減する

フィールドは敵味方が共用する戦場の状態です。自分が展開したフィールドを敵が利用する場合もあります。戦闘中に存在できるのは魔石4属性のうち1つだけで、同属性の再展開は不発、異属性を展開すると既存フィールドを置き換えます。フィールド倍率はスレイヤーの成立とは無関係です。

バリアは付与された側だけに作用し、同じ属性を重ねても効果は増えません。

よくある質問

転職したら、以前の職業で覚えた技は使えませんか？

使えます。現在の職業は使用条件ではありません。ただし、技が必要とする装備を外している場合は設定できません。

装備を変えたら、設定していた技が消えました

現在の装備で使えない技は、戦闘設定から外れることがあります。/skillsで必要装備を確認し、装備を戻すか、「スキルセット変更」で別の技を設定してください。

S1は1ターンだけ使う技ですか？

いいえ。S1は1ターン準備し、その次のターンに発動するため、合計2枠を使います。

リフトスレイヤーを使うと、相手はダウンしますか？

スレイヤーだけではダウンしません。ダウンを付ける技には、別の効果として「ダウンを付与」と表示されます。

連携中に通常攻撃を挟むと、その場で0になりますか？

その場では0になりません。同じターン中にスレイヤーが1回でも成功すれば維持されます。1ターンを通して成功しなかった場合、ターン終了時に0へ戻ります。

1ヒットで2種類のスレイヤーが出たら、2連携増えますか？

増えるのは1です。連携はスレイヤーの種類数ではなく、スレイヤーが成功したヒット数で数えます。

常態リフトにも連携できますか？

できます。常態姿勢はスレイヤーを受けても消えないため、条件を整えればリフトスレイヤーを続けられます。

まず何を組めばよいですか？

最初は「姿勢を付ける技1つ＋その姿勢のスレイヤー1つ」がおすすめです。パーティなら付与役を先、スレイヤー役を後に置き、ログの連携表示を確認してから属性スレイヤーや多段攻撃を加えてみてください。
